# Improvements backlog

The backlog lives in **[GitHub Issues](https://github.com/Solus90/dcma-site/issues)** now — work from tickets, not this file.

Every item that used to be here is an open issue (#30–#43). New ideas → open an issue rather than editing a doc.

Rough label conventions:
- `enhancement` — a feature or capability to add
- `bug` — something already shipped that's wrong or misleading
- `good first issue` — small, self-contained, no context needed
- `help wanted` — blocked on a decision, access, or input from the collective

Operational runbooks (DNS cutover, how deploys and content revalidation work) stay in [`DEPLOYMENT.md`](./DEPLOYMENT.md) — that's reference material, not a backlog.
